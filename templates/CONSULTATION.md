# Consulting Checkpoints

Complete a checkpoint whenever `attempts.md` contains the configured number
of consecutive failed approaches since the previous checkpoint. Read
`consulting/STUCK-ROUTER.md` first, then at least one matching guide.

Keep each field on one line so the harness can validate it. `Covers through
attempt` is the attempt number that triggered this checkpoint.
