# CV 1:2 Auto-Bind Setting

## What “1:2” means here

This compiler feature binds or tiles mixed Cube–Vector work across one AIC and
two AIV sub-blocks. It is not merely the physical fact that architecture 3510
contains two AIVs per AIC.

## Control and priority

The wiki shows this priority function:

```text
if enable_auto_bind_sub_block is not None:
    effective = enable_auto_bind_sub_block       # explicit user override
else:
    effective = auto_tile_and_bind_subblock      # module-derived value

--enable-auto-bind-sub-block=<effective>
```

The wiki calls the feature default-on and gives
`enable_auto_bind_sub_block=False` as the explicit disable. The inspected
compiler snapshot derives `auto_tile_and_bind_subblock` from the module and
can disable it when a module marker says so.

## Verification

### E1 — request

Capture both the explicit override and module-derived value, then confirm the
generated command's final `--enable-auto-bind-sub-block=<value>`.

### E3 — positive IR marker

The wiki says the transform is active when at least one of these HIR operations
is marked `tiled_op`:

```text
hivm.hir.store
hivm.hir.copy
hivm.hir.indirect_store
```

Search the recompiled after-pass IR and preserve the containing function and
operation. A `tiled_op` string elsewhere is not enough.

### E4 — runtime

Confirm that one AIC and the intended one/two AIV participants execute and
that cross-core synchronization terminates for full and tail phases. Device
core counts are corroborating evidence, not a substitute for IR.

## Negative cases

- Explicit `False` overrides module auto-detection.
- A module-level disable marker can make the derived value false.
- Flag `true` with no eligible HIR store/copy proves only E1.
- A physical 1:2 machine does not prove the kernel used 1:2 binding.

## Correctness audit

For each tiled operation, verify participant count, partition boundary,
output ownership, event counts, and final partial tile. A faster 1:2 schedule
is invalid if one AIV observes stale data or a tail waits for a nonexistent
participant.
